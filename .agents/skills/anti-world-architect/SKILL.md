# Anti Survivors 월드 & 스테이지 생성 파이프라인 스킬 (`anti-world-architect`)

본 스킬은 Anti Survivors 게임에 새로운 전장(예: 월드 3 불타는 화산 요새, 월드 4 혹한의 설원 유적 등)을 추가할 때, **지형 규격, 60fps 무렉 환경 연출, 필드 장애물 3종, 테마 몬스터 15종, 4대 보스 패턴, 20~25스테이지 타임라인, 스테이지 선택 모달 UI**를 누락 없이 표준 아키텍처에 맞게 일괄 구축하도록 지원합니다.

---

## 1. 신규 월드 설계 불변 원칙

1. **지형 형태와 바운더리 동기화**:
   - 오픈 필드형 (예: 3200 x 3200 정사각) 또는 협곡형 (예: 6000 x 1600 가로 협곡) 중 선택.
   - 플레이어, 그라운드 몬스터, 장애물, 보석 드랍 경계는 반드시 `getWorldBoundaries()`를 통해 일괄 제어되어야 합니다.
2. **60fps 무렉 환경 연출 원칙 (Zero GC)**:
   - 배경 파티클(기포, 화산재, 눈보라 등)은 매 프레임 `new Particle()`을 생성하지 않고 **고정 객체 풀(60~90개)**을 재순환하여 가비지 컬렉션(GC) 렉을 원천 차단합니다.
   - Canvas 2D `shadowBlur`를 남발하지 않고 `arc`, `ellipse`, 가벼운 반투명 색상(`rgba`)을 활용합니다.
3. **환경 장애물 3종 규격**:
   - 🪨 **바위/구조물형**: 체력 120, 단단한 외형, 파괴 시 높은 확률의 보석/아이템.
   - 🌿 **식물/자연형**: 체력 60, 가벼운 오브젝트.
   - 📦 **보물상자형**: 체력 80, 파괴 시 100% 확정 특수 아이템(자석/폭탄/얼음/포션/금화) 드랍.
4. **4대 보스 티어 구성**:
   - **5스테이지 (미니보스)**: 빠른 기동성, 1~2개 기본 탄막/돌진 기믹 (HP 약 8,000~10,000).
   - **10스테이지 (중간보스)**: 넉백 면역, 광역 슬로우/충격파 (HP 약 24,000~28,000).
   - **15스테이지 (대보스)**: 고속 돌진, 대형 나선/방사형 탄막 (HP 약 60,000~75,000).
   - **20스테이지 (최종보스)**: 넉백 면역, 즉사급 3중 복합 탄막 패턴 (HP 약 120,000~150,000).

## 2. 신규 월드 스캐폴딩 스크립트 실행

새로운 월드 뼈대 코드를 생성하려면 다음 명령어를 실행합니다:

```bash
# 기본 사용법 (대화형 또는 기본값 스캐폴딩)
node .agents/skills/anti-world-architect/scripts/scaffold_world.js 3 "화산 요새" 6000 1800
```

### 아규먼트 설명:
- `arg1`: 월드 번호 (예: 3)
- `arg2`: 월드 이름 (예: "화산 요새")
- `arg3`: 맵 가로 너비 (px, 기본 6000)
- `arg4`: 맵 세로 높이 (px, 기본 1800)

스크립트를 실행하면 다음 파일들에 삽입해야 하는 표준 뼈대 코드가 즉시 출력됩니다:
1. `index.html`: `#stageSelectModal` 내 스테이지 카드 마크업
2. `style.css`: 테마 네온 컬러 및 뱃지 스타일
3. `js/obstacles.js`: 신규 3종 장애물 타입 및 절차적 렌더러
4. `js/enemies.js`: 신규 15종 테마 몬스터 스펙 테이블
5. `js/bosses.js`: 4대 테마 보스 생성자 및 패턴 AI
6. `js/waveManager.js`: 20스테이지 웨이브 타임라인 및 4대 보스 스폰 연동
7. `js/main.js`: 맵 크기 바운더리 및 고정 객체 풀 렌더러
