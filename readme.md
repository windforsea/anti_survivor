# ⚔️ Vampire Survivors Web - 개발 현황 및 요구사항

## 📋 완료된 요구사항
- [x] **1. 게임 중 정지 기능**: `ESC` / `P` 키 토글 및 우측 상단 `⏸️` 버튼, 일시정지 모달 레이어(계속하기/재시작) 제공
- [x] **2. 각종 장애물 추가**:
  - **비파괴 장애물 (바위, 고대 나무)**: 크기 2배 확장(반경 48px), 플레이어와 몬스터의 이동을 가로막는 단단한 지형 충돌체
  - **파괴 가능 장애물 (나무 상자/오크통)**: 개체수 1/2로 희소화 조정, 체력 22, 파괴 시 파편 파티클과 함께 경험치 보석, 체력 회복 포션, 자석, 폭탄, 얼음 드랍
- [x] **3. 던지는 단검 추가 (직진 관통형)**: 조준 방향으로 고속 비행하며 다수의 적을 관통하는 투사체 무기 신규 추가
- [x] **4. 각 원거리무기별 사거리 차등화**: 단검(약 290px) = 산탄총(약 280px) < 마법 화살(약 700px 화면 전체 유도)
- [x] **5. 근거리 채찍 추가**: 일반 근접보다 긴 사거리(165px), **이등변 삼각형(밑변이 원주인 부채꼴 호 112°) 전체를 긁어내며 타격**, 강화에 따라 **1렙 앞 1회 → 2렙 앞 1회 뒤 1회 → 3렙 앞 2회 뒤 1회 → ... → 최종 앞 3회 뒤 3회** 전후방 교차 난무
- [x] **6. 단검 범위 축소 (일반 검 반영)**: 기본 지급 근접 무기인 '일반 검'의 타격 범위를 슬림하게 축소하여 정밀한 타격감 제공
- [x] **7. 공격 시 애니메이션만 출력, 원형 인디케이터 숨김**: 불필요한 테두리 선을 걷어내고 부드러운 부채꼴 잔상 및 무기 스프라이트 휘두르기 모션 출력

- [x] **8. 무기 발사 방향 분화 및 근거리 메리트 강화**:
  - **던지는 단검**: 가장 가까운 몬스터를 자동 조준하여 직진 투척
  - **산탄 총포**: 플레이어가 바라보고 있는 방향(facing)으로 전방 부채꼴 일제 사격
  - **근접 무기 데미지 대폭 강화**: 근접 리스크 보상을 위해 도끼(55), 채찍(42), 일반 검(32) 등 근접 공격력을 상향하고 원거리 단타 피해(15~18)와 차등화
- [x] **9. 보스 몬스터 폭탄 저항 추가**: 필드 드랍 폭탄(TNT) 습득 시 보스가 허무하게 죽지 않도록 최대 피해량을 최대 HP의 10% 또는 최대 250으로 제한
- [x] **10. 성수(성역) 명칭 및 연출 개편**: 기존 성역 장판을 '성수'(`holyWater`)로 개편하고 청록/푸른빛 정화 이펙트와 전용 아이콘 적용

## 🌟 3대 진화 무기 체계
1. **회전 도끼 (`spinningAxe`)**: **일반 검(6강) + 도끼(6강)**
   - 플레이어 주변을 초고속 회전하는 거대 도끼들로 적과 상자를 갈아냄
2. **칼날 채찍 (`bladeWhip`)**: **채찍(6강) + 던지는 단검(6강)**
   - 채찍 끝에 날카로운 단검들이 결합되어 **초장거리(310px) + 135° 대형 부채꼴 전체를 긁어내는 전후방 6회 폭풍 난무**
3. **홀리 산탄총 (`holyShotgun`)**: **산탄 총포(6강) + 성수(6강)**
   - 산탄 총포의 많은 탄환 수(6발 이상)를 전방으로 발사하며, 탄환 적중 시 **35px 좁은 반경의 성스러운 폭발(스플래시 20 피해)**을 일으켜 밀집된 적 무리를 일망타진
