# ⚔️ Anti Survivors (안티 서바이버즈)

웹 기반 탑다운 뱀파이어 서바이벌라이크 액션 게임입니다.  
HTML5 Canvas, Pure JavaScript(ES6+), Web Audio API를 기반으로 외부 라이브러리/프레임워크 없이 초경량 네이티브로 구현되었습니다.

## 🕹️ 조작 방법 및 편의 시스템

### 1. 기본 조작
- **PC 키보드 이동**: `W`, `A`, `S`, `D` 또는 방향키 (`↑`, `←`, `↓`, `→`)
- **일시정지 / 계속하기**: `ESC` 또는 `P` 키, 화면 우측 상단 `⏸️` 버튼
- **전체화면 전환**: 화면 상단 HUD 우측 `⛶` 버튼 클릭/터치

### 2. 스마트폰 모바일 조작 및 편의 최적화
- **전 화면 동적 플로팅 가상 조이스틱 (Full-Screen Floating Joystick)**:
  - 무기/스킬이 100% 자동 조준 및 자동 공격되므로 별도의 공격 버튼이 필요 없습니다.
  - 상단 HUD(상단 60px)를 제외한 **게임 화면 가로 전체(100%) 어디든 엄지손가락을 터치하면 그 자리에 조이스틱이 즉시 생성**됩니다.
  - **오른손잡이, 왼손잡이, 양손 모두 편한 위치에서 조작**할 수 있으며, 손가락을 떼면 즉시 숨겨져 시야를 가리지 않습니다.
  - 레벨업 카드 선택창 등 모든 모달 팝업 시에는 상위 레이어(`z-index: 100`) 분리와 게임 상태 검증으로 조이스틱 반응이 완벽히 차단됩니다.
- **원터치 모바일 전체화면 & 가로 락 (`⛶`)**:
  - 상단 HUD의 `⛶` 토글 버튼 터치 시 브라우저 주소창과 내비게이션 바를 즉시 숨기고 가로 화면(`landscape`)으로 고정합니다.
- **화면 꺼짐 방지 (Screen Wake Lock API)**:
  - 플레이 도중 조작이 잠시 멈춰도 스마트폰 화면이 어두워지거나 잠기지 않도록 방지합니다.
- **모바일 햅틱 진동 피드백 (Tactile Vibration)**:
  - 몬스터 피격 시: `35ms` 타격 진동
  - 레벨업 시: `[30ms, 40ms, 30ms]` 리듬 진동
  - 부활 및 최종 보스 격파 시: 묵직한 다중 진동
  - 로비 강화 구매 시: 터치 피드백
- **제스처 오동작 방지**:
  - CSS `touch-action: manipulation` 및 전역 터치 최적화를 적용하여 브라우저의 더블탭 줌, 롱터치 텍스트 선택, 스크롤 튕김을 차단했습니다.

### 3. 레벨업 & 카드 선택 시스템
- **카드 선택 조작**:
  - 마우스 좌클릭 또는 모바일 터치
  - 숫자 단축키: `1`, `2`, `3` 키로 즉시 해당 번호 카드 선택
  - 키보드 포커스: 방향키(`←`, `→`, `↑`, `↓`)로 카드 포커스 이동 후 `Enter` 또는 `Space` 키로 확정
- **새로고침 (🎲 Reroll)**: 한 판당 최대 3회 카드 선택지 재추첨 가능
- **스킵 (⏩ Skip)**: 카드를 넘기는 대신 캐릭터 체력 +10 즉시 회복
- **인벤토리 슬롯 한도**: 무기 최대 **6종**, 캐릭터 패시브 최대 **6종** 동시 장착 가능

## 🛡️ 데이터 보안 및 무결성 검증 체계 (Security & Anti-Tamper)

순수 클라이언트 웹 게임의 취약점인 개발자 도구 조작 및 스토리지 변조를 방어하기 위해 다층 보안 아키텍처가 적용되었습니다.

### 1. FNV-1a 32-bit 해시 체크섬 서명 (`SaveManager`)
- **솔트(Salt) 기반 서명 발급**:
  - 보유 금화(`gold`)와 각 영구 업그레이드 레벨(`upgrades`) 데이터를 정규화한 후, 독자적인 비밀 솔트 키를 조합하여 **FNV-1a 32-bit 해시 서명(`_sig`)**을 자동 생성 및 첨부합니다.
- **실시간 무결성 위변조 감지**:
  - 브라우저 개발자 도구(F12) 콘솔이나 Application 스토리지 탭에서 수치를 임의로 조작하면 계산된 해시와 서명이 불일치하게 되며, **변조가 감지된 즉시 데이터가 안전하게 파기 및 초기화**됩니다.
- **안전한 데이터 마이그레이션**:
  - 보안 기능 도입 이전의 기존 플레이어 세이브 데이터는 1차 정상 범위 검증(수치 타당성 검사)을 거친 후, 자동으로 최신 보안 서명이 부여되어 세이브 유실 없이 영구 보존됩니다.

### 2. XSS (Cross-Site Scripting) 방어
- 챔피언 명예의 전당 등록 시 사용자 입력값(닉네임, 명언)에 대해 `<script>`, `onerror` 등 악성 HTML/스크립트 태그를 완벽히 무력화하는 **`sanitizeText` 정규식 살균 필터링**을 거쳐 저장 및 렌더링됩니다.

### 3. 콘솔 치트 1차 감시
- 전역 `window.game` 인스턴스에 대한 비정상적인 전역 스코프 조작을 방어하고, 주기적인 세이브 동기화 시 `SaveManager` 무결성 검증 파이프라인을 강제합니다.

## 🚀 실행 및 접속 방법 (How to Run)

### 방법 1. 24시간 언제 어디서나 웹 접속 (Vercel 클라우드 호스팅)
- 로컬 서버를 구동할 필요 없이, 스마트폰/태블릿/PC 브라우저에서 바로 접속할 수 있습니다.
- **공식 저장소**: [https://github.com/windforsea/anti_survivor](https://github.com/windforsea/anti_survivor)
- GitHub 원격 저장소(`master` 브랜치)와 Vercel이 연동되어 있어, 커밋 푸시 시 15초 내에 최신 버전으로 자동 배포됩니다.

### 방법 2. 원클릭 실행 (Windows 로컬 구동)
- 루트 디렉토리의 **`start_server.bat`** 파일을 더블클릭합니다.
- Node.js 설치 확인 후 기본 웹 브라우저(`http://localhost:3000`)를 자동 호출하며 서버가 즉시 기동됩니다.

### 방법 3. 콘솔 수동 실행
```bash
# 로컬 서버 실행 (Node.js 기본 내장 모듈만 사용, 별도 npm install 불필요)
node server.js

# 브라우저 접속: http://localhost:3000
# (동일 Wi-Fi 공유기 내 스마트폰/태블릿은 콘솔에 안내되는 LAN IP로 접속 가능)
```
