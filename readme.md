# ⚔️ Anti Survivors (안티 서바이버즈) - 수묵화풍 비주얼 리메이크

> **조선 수묵 다크 판타지(Ink-Wash Calligraphy Dark Fantasy) 탑다운 생존 서바이벌 액션**  
> 거친 붓터치와 농담(濃淡)의 먹선, 닥종이 한지 위에서 펼쳐지는 극한의 탄막 생존 액션.  
> HTML5 Canvas, Vanilla JavaScript(ES6+), Web Audio API 기반 순수 네이티브 초경량 무결점 구현.

---

## 🎨 100% 수묵화풍(Ink-Wash) 비주얼 리메이크

- **일필휘지(一筆揮之) 서예 검기 액션**: 철검과 도끼의 부채꼴 회전 궤적과 날카로운 먹선 비백(飛白) 연출로 적의 원거리 탄막을 시원하게 베어내어 무효화합니다.
- **칼날 끝(Tip) 동기화 궤적**: 근접 무기의 수묵 궤적 반경을 칼날 끝 위치에 1:1로 일치시키고, 공격 범위(`area`) 증가 시 궤적이 칼날과 함께 자연스럽게 확대됩니다.
- **128×128 초고해상도 수묵 영웅 6종**: 방랑 기사, 화염 마도사, 그림자 암살자, 해골 성직자(모티스), 바람의 궁수(실프), 심연의 워록(말라카르)의 독보적인 먹선 실루엣과 수묵 잔상.
- **30종 일반 몬스터 & 13종 보스 전원 128×128 수묵화 리메이크**: 송연먹 갈필과 단청 안광이 살아 숨쉬는 요괴 군단과 심해 4대 보스를 포함한 13종 보스의 위압적인 수묵 래스터라이저.
- **월드 1 & 월드 2 수묵 장애물 6종**: 기암괴석, 천년고목, 보물궤짝 및 심해 산호 암초, 유동하는 거대 해초, 침몰선 궤짝의 조류 만곡 물리 연동.
- **전통 조선 닥종이(한지) & 다크 잉크 비네팅**: 512×512 오프스크린 한지 바닥재 베이킹과 외곽 먹물 번짐 비네팅으로 몰입도 극대화.
- **60 FPS 무렉 하이엔드 렌더링**: 뷰포트 컬링 바운딩 박스 최적화 및 무GC(Garbage Collection) 파티클 풀링으로 후반부 수백 마리 적과 탄막 속에서도 프레임 드랍 0% 유지.

## 🎮 핵심 게임 시스템 (Core Mechanics)

- **17종 기본 무기 & 17대 특수 합성 진화 무기 (총 34종 고유 무기)**:
  - 레거시 별칭(산성웅덩이 등)을 완전히 퇴출하고 정규 무기 ID로 전역 단일화되었습니다.
  - 기본 무기 5레벨 달성 시 직관적인 2단계 합성 메커니즘을 통해 전장을 뒤흔드는 진화 무기로 개화합니다.
  - **진화 무기 목록**: 생츄어리, 모닝스타, 아포칼립스 혜성, 폭풍칼날, 테슬라 산탄총, 독눈보라, 벼락검, 화염도끼, 서리채찍, 산탄표창, 신성화살, 역병, 태풍의 눈, 황혼의 나선, 지옥불 기둥, 그림자 소용돌이, 대천사의 심판 (총 17종).
- **무기 유효 사거리 체크 및 스마트 홀드 파이어 (Smart Hold Fire)**:
  - 원거리 및 근접 무기가 허공에 탄환을 낭비하지 않도록, 유효 사거리 내에 적이 감지되지 않으면 쿨타임을 보존하며 대기합니다.
  - 전장 전역 번개, 랜덤 낙하, 상시 결계 무기(번개반지, 성수, 성역, 생츄어리, 역병, 폭풍칼날, 어둠의 보주 등)는 사거리 제한 없이 상시 작동합니다.
- **도끼 360도 회전 & 폭풍칼날 적 탄막 요격 시스템**: 몰려오는 적의 투사체와 보스 탄환을 회전 궤적으로 완벽하게 삭제.
- **16종 인게임 패시브 & 9종 영구 강화 엽전 상점**: 흡혈, 방벽, 가시 갑옷, 치명타 증폭 등 무궁무진한 빌드 구성.
- **2개의 특색 있는 수묵 전장**:
  - **월드 1: 심연의 부유섬 (25단계 극한 웨이브)** - 18분 45초 동안 몰려드는 지상/공중 혼합 요괴 군단과 흑풍 사신 강림.
  - **월드 2: 심해 대협곡 (20단계 횡스크롤 협곡 전장)** - 좁고 긴 해저 협곡에서 몰려오는 15종의 심해 요수와 태고신 다곤.
- **실시간 글로벌 명예의 전당**: Vercel Serverless API와 FNV-1a 해시 체크섬 보안이 적용된 실시간 클리어 랭킹 시스템.
- **모바일/태블릿 터치 지원**: 전 화면 동적 플로팅 가상 조이스틱과 서화첩 모달 UI 반응형 지원.

## 🚀 실행 및 플레이 방법 (How to Run)

### 방법 1. 웹 브라우저 즉시 플레이 (Vercel 클라우드 호스팅)
- 별도 설치 없이 PC, 모바일, 태블릿 브라우저에서 즉시 실행됩니다.
- **플레이 주소**: [https://anti-survivor.vercel.app](https://anti-survivor.vercel.app)
- **공식 저장소**: [https://github.com/windforsea/anti_survivor](https://github.com/windforsea/anti_survivor)

### 방법 2. 원클릭 실행 (Windows 로컬 구동)
- 프로젝트 루트 디렉토리의 **`start_server.bat`** 파일을 더블클릭합니다.
- Node.js 설치 확인 후 기본 웹 브라우저(`http://localhost:3000`)를 자동 호출하며 서버가 즉시 기동됩니다.

### 방법 3. 콘솔 수동 실행
```bash
# 에셋 일괄 빌드 (필요 시)
node generate_assets.js

# 로컬 개발 서버 구동
node server.js
```
브라우저에서 `http://localhost:3000` 접속 후 플레이.
