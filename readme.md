# ⚔️ Vampire Survivors Web (VAM)

웹 기반 뱀파이어 서바이벌 류 탑다운 로그라이트 액션 게임입니다.  
HTML5 Canvas, Pure JavaScript(ES6+), Web Audio API를 기반으로 외부 라이브러리/프레임워크 없이 초경량 네이티브로 구현되었습니다.

## 🎮 게임 실행 방법

### 방법 1. 원클릭 실행 (Windows 권장)
- 루트 디렉토리의 **`start_server.bat`** 파일을 더블클릭합니다.
- Node.js 설치 확인 후 기본 웹 브라우저(`http://localhost:3000`)를 자동 호출하며 서버가 기동됩니다.

### 방법 2. 콘솔 수동 실행
```bash
# 1. 의존성 설치 불필요 (Node.js 기본 내장 모듈만 사용)
# 2. 로컬 서버 실행
node server.js

# 3. 브라우저 접속: http://localhost:3000
# (동일 Wi-Fi 공유기 내 스마트폰/태블릿은 콘솔에 안내되는 LAN IP로 접속 가능)
```

- [x] **14. 몬스터 피격 및 처치 시 게임 멈춤(Freeze) 버그 수정**:
  - **원인 분석**: 몬스터(박쥐)가 플레이어의 기본 무기(일반 검) 사거리(80px)에 진입하여 공격을 받아 체력이 0이 되는 순간, 사망 처리 루틴에서 `sounds.playKill()`을 호출하나 오디오 엔진에 해당 메서드가 정의되어 있지 않아 `Uncaught TypeError` 예외가 발생하고 `requestAnimationFrame` 렌더링 루프가 멈추던 문제 해결
  - **누락 사운드 추가 및 Safe Proxy 방어막 구축**: 누락되었던 `playKill()`(처치 파열음), `playMagic()`(마법 발사음), `playBossStomp()`(보스 발구르기 충격파) 신규 사운드를 신디사이저에 정식 구현하고, 향후 임의의 사운드 함수 호출 시에도 게임이 절대 크래시되지 않도록 `Safe SoundEngine Proxy` 안전 가드 적용 완료
